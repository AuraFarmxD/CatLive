ПРОТОТИП — СНОС ВИНДЫ

SHUTDOWN

Прототип утилиты для Windows. При запуске открывается окно cmd с требованием ввести пароль. Если пароль не введён за отведённое время — компьютер выключается.

⚠ ВНИМАНИЕ
  • При запуске открывается окно cmd с требованием пароля.
  • Даётся 2 минуты на ввод.
  • Если пароль не введён — ПК выключается.
  • Неверный ввод — тоже выключение.
  • Пароль не публикуется.
Последствия при неверном вводе:
  • Компьютер выключается принудительно.
  • Все несохранённые данные теряются.
  • Система загрузится как обычно — данные не удаляются.
  • Для повторного запуска нужно включить ПК снова.

Пароль не публикуется. Он выдаётся только тем, кому доверяем.
